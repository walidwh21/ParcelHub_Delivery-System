# ParcelHub documentation

```text
docs/
├── visuals/
│   ├── branding/      banner.png
│   ├── ui-previews/   six interface previews rendered with sample data
│   ├── flows/         booking-flow, rider-flow, status-machine
│   └── structure/     system-overview, data-model, domain-layers
└── sources/
    ├── mermaid/       *.mmd – text source of every chart in visuals/flows and visuals/structure
    └── drawio/        use-case, class, activity and ER diagrams (editable)
```

Edit a `.mmd` file and re-render it with any Mermaid renderer to refresh the matching PNG.
